# Area rents

## `sample_rents.csv` is not real data

No real rent dataset is included yet. `sample_rents.csv` is a placeholder
generated by `jobs/make_sample_rents.py`: a synthetic figure per area that only
depends on distance from the city centre. Every row has `is_sample=true`, and
the site marks these figures with an asterisk. Do not quote them as rents.

## Adding real data

Provide a CSV file (UTF-8, comma-separated, with this header row) and load it:

```bash
uv run python -m jobs.load_rents path/to/rents.csv
```

| Column | Meaning | Example |
| --- | --- | --- |
| `city_id` | `berlin` or `munich` | `munich` |
| `area_external_id` | Official key of the area: Berlin `sch`, Munich `sb_nummer` (see the sample file for the full list) | `03` |
| `area_name` | For readability only; not used to match | `Maxvorstadt` |
| `monthly_rent_eur` | Monthly rent in EUR, greater than 0 | `890.00` |
| `basis` | What the figure measures | `median asking rent, 1-room flat up to 40 m2` |
| `source` | Name of the publication or dataset | `City housing report 2025` |
| `source_url` | Link to the source; may be empty | |
| `as_of` | Date the figure refers to, `YYYY-MM-DD` | `2025-06-30` |
| `is_sample` | `true` or `false`; `false` for real data | `false` |

Rules:

- An area that is left out keeps a rent of UNKNOWN; nothing is estimated for it.
- A real figure always takes precedence over a sample figure for the same area;
  among real figures the latest `as_of` is used.
- A file with any invalid row is rejected as a whole, with the line numbers.
